# Hospital-Management-System
Project Overview

Build a Java-based Hospital Management System with:

Features
Patient Registration
Doctor Assignment
Appointment Booking
Billing System
🎯 Concepts Covered
Concept	Usage
OOP	Classes & Objects
Inheritance	Person → Patient/Doctor
ArrayList	Store records dynamically
Encapsulation	Data hiding
Methods	Functional operations
Menu-driven System	User interaction
🧠 Real World Understanding

In a hospital:

Patients register
Doctors are assigned
Appointments are booked
Bills are generated

This project simulates all these operations.
